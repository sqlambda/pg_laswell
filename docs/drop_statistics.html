drop_statistics

Synopsis

{
  "kind": "drop_statistics",
  "schema": <required>,
  "name": <required>
}

Parameters

schemarequired
 
namerequired
 
Any key not listed here is refused, not ignored: a key this binary skips and a newer one honours would be a silent difference between what was reviewed and what ran.

Examples

From the conformance suite, which plans this intent and applies it to a real PostgreSQL on every test run:

{
 "kind": "drop_statistics",
 "schema": "cf",
 "name": "t_corr"
}

Afterwards, SELECT count(*)::text FROM pg_statistic_ext WHERE stxname='t_corr' returns 0.
